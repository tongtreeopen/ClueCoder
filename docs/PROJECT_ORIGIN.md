# ClueCoder project origin

ClueCoder is developed on top of [CoreCoder](https://github.com/he-yufeng/CoreCoder). Its development adds traceable execution, recoverable state, evidence-based Goal verification, memory and context management, controlled Docker execution, structured review, and independent evaluation. Original upstream authorship and the MIT license are preserved.

The distribution, Python import package and CLI are `cluecoder`. Project configuration uses `CLUECODER_*`; application state uses `.cluecoder`. Generic provider settings such as `OPENAI_API_KEY` remain supported.

Repository: https://github.com/tongtreeopen/ClueCoder.

Validation claims are tied to the recorded revision, source hashes and actual check scope. Historical logs, tags and raw artifacts retain their recorded identifiers so their integrity can be verified. Historical results are separate from checks of the current release.
