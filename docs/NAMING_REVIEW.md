# ClueCoder 来源与发布检查

ClueCoder 在 [CoreCoder](https://github.com/he-yufeng/CoreCoder) 基础上开发，保留原始作者署名与 MIT 许可证。项目维护者为 Tong ShuKai。

当前 Python 包、CLI 和发行包名称均为 `cluecoder`，配置前缀为 `CLUECODER_*`，状态目录为 `.cluecoder`。仓库为 [tongtreeopen/ClueCoder](https://github.com/tongtreeopen/ClueCoder)，当前保持私有；尚未发布到 PyPI。

来源与验证以 [项目来源](PROJECT_ORIGIN.md)、[发布说明](RELEASE.md)及其中链接的验证报告为准。测试结论绑定实际 revision；历史原始产物与哈希不重写。
